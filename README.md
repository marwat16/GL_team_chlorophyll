# GL_team_chlorophyll

Replication package for our experiment comparing the energy consumption, energy efficiency and runtime performance of scientific code generated by ERA with human-written code for the same tasks. The experiment covers five tasks (scRNA-seq, COVID-19, Geospatial Analysis, GIFT-Eval and ZAPBench) with 140 runs in total. This repository is a fork of [Experiment Runner](https://github.com/S2-group/experiment-runner).

## Repository structure

```
experiment_code/            One folder per task, each with AI.sh, Human.sh and a README with its setup
  Covid19/  GIFT-eval/  Geospatial/  scRNA/  ZapBench/
  warmup.py                 Warm-up script, run once before the first run
experiment-runner/          Experiment Runner
  greenlab/RunnerConfig.py  Our experiment configuration (run table, cool-down, measurement)
  greenlab/experiments/full_experiment/
                            Results of all 140 runs: run_table.csv and one energibridge.csv per run
data_analysis/              Data processing (Python) and statistical analysis (R), see its README
  data/raw/                 Quality outputs of the runs, copied from the server
  data/processed/           Per-run tables produced by the processing step
  processing/               Python scripts that compute energy and quality per run
  analysis/                 R scripts; run_all.R is the main file
  output/                   All figures and tables used in the report
```

## Running the experiment

1. Set up every task as described in the README of its folder in `experiment_code/`.
2. Install Experiment Runner's dependencies:
   `pip install -r experiment-runner/requirements.txt`
3. Run the experiment from the repository root:
   `python experiment-runner/experiment-runner/ experiment-runner/greenlab/RunnerConfig.py`

The runs are executed in one randomized order, with a 60-second cool-down after every run. The results are written to `experiment-runner/greenlab/experiments/full_experiment/`.

**Note on the energy column:** the `energy consumption (J)` column in `run_table.csv` is computed by Experiment Runner during the experiment and is not used in the analysis. It double-counts the PP0 and PP1 domains, omits the GPU, and does not correct overflows of the RAPL energy counter. The analysis recomputes the energy of every run from the raw `energibridge.csv` files (CPU package energy with overflow correction plus GPU energy).

## Requirements

- **Experiment:** Linux machine with an NVIDIA GPU, Python 3.12 and [EnergiBridge](https://github.com/tdurieux/EnergiBridge)
- **Analysis:** Python 3.12 and R 4.6.1, with the packages listed in `data_analysis/README.md`

## Reproducing the analysis

From the repository root, on macOS and Linux:

```bash
cd data_analysis
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python processing/run_all.py
Rscript analysis/run_all.R
```

The R packages are installed once with the command given in `data_analysis/README.md`, which also covers Windows and the system libraries needed on Linux. All figures and tables are written to `data_analysis/output/` and match those in the report. Every output is committed, so these steps are only needed to reproduce the results. See `data_analysis/README.md` for details on each script.
